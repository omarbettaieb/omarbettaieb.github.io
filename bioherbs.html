01 / PROJECT OVERVIEW

A brand-aligned storefront, built end to end.

I built Bioherbs' Shopify store from scratch using a Shopify theme as a starting point, adapting the storefront to the brand. Beyond theme configuration, I developed product page layouts with Liquid, JavaScript and CSS for a more tailored mobile shopping experience.

  • Store setup and theme customization
  • Homepage and product discovery
  • Custom Liquid product templates
  • JavaScript and CSS product-page customization
  • Brand-aligned product storytelling
  • Mobile-focused purchase interface

03 / TECHNICAL FOCUS

Custom product pages, not just a theme preset.

The strongest technical work in this build is the custom product-page implementation with Liquid, JavaScript and CSS. The resulting interface presents detailed product descriptions, product-specific highlights, reviews, discount information, quantity controls and a visible purchase action.

LiquidJavaScriptCSSProduct UXResponsive UI

The custom work here differs from VegaLife: Bioherbs emphasizes tailored product-page UX, while VegaLife highlights custom bundle and upsell logic.

Scope note: collection filters, reviews and pricing are visible store features; they are not presented as custom-developed from scratch unless separately confirmed. No unverified conversion uplift is claimed.
